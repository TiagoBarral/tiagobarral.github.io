## What I built

Write a plain description of the project. Keep it specific: what problem it solves, what it does, and what someone can try.

## What I was trying to learn

Explain the skill or idea you were practicing. For example: static site generation, routing, CSS layout, API calls, tests, or deployment.

## What went wrong

Describe the mistakes and dead ends. This is the part that makes the page useful later.

## Biggest challenge / bug

Write about the hardest bug or design problem. Include symptoms, what you checked, and what finally fixed it.

## What I learned

Summarize the lessons in a way that would help you repeat the project with less confusion next time.

## What I would do differently

Name one or two concrete improvements. Avoid turning this into an endless rewrite list.
