Today I set up the first version of this site.

The important decision was to keep the structure simple: Markdown content, a few Hugo layouts, and one CSS file. That should make writing easier than maintaining the site itself.

## What I learned

Small static sites do not need much machinery. A clear content format and quiet typography can do most of the work.
